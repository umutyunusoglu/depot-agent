# Valor 3-Tab Shingles (SHG-004 Black)

## Overview
Valor is an economy three-tab asphalt shingle with a flat, uniform appearance. Common on rental properties, sheds and budget re-roofs.

## Coverage
Each bundle covers 33.3 sq ft. 3 bundles make 1 roofing square (100 sq ft).

## Wind performance
Wind rating: 60 mph.

## Installation
Minimum roof slope: 4:12. Not approved for low-slope roofs.
Minimum application temperature: 40°F (4°C).

## Warranty
25-year limited warranty, prorated after year 5.
