# Summit Pro Laminate Shingles (SHG-003 Charcoal)

## Overview
Summit Pro is a premium laminated architectural shingle, heavier than Ridgeline, with a deeper shadow line. Colour: Charcoal.

## Coverage
Each bundle covers 33.3 sq ft. 3 bundles make 1 roofing square (100 sq ft).

## Wind and fire performance
Wind rating: 130 mph with a 4-nail pattern, 150 mph with a 6-nail pattern.
Fire rating: Class A (ASTM E108).

## Installation
Minimum application temperature: 40°F (4°C). Do not install below this temperature: the shingles become brittle and may crack when nailed.
Minimum roof slope: 2:12. Slopes between 2:12 and 4:12 require double underlayment.

## Warranty
Limited lifetime warranty, non-prorated for the first 15 years. Algae resistance warranty: 15 years.
