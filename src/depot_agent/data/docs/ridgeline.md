# Ridgeline Architectural Shingles (SHG-001 Charcoal, SHG-002 Weathered Wood)

## Overview
Ridgeline is a laminated architectural asphalt shingle with a dimensional, wood-shake look. Available colours: Charcoal (SHG-001) and Weathered Wood (SHG-002).

## Coverage
Each bundle covers 33.3 sq ft. 3 bundles make 1 roofing square (100 sq ft).

## Wind and fire performance
Wind rating: 130 mph with the standard 4-nail pattern. No higher rating is available for this product.
Fire rating: Class A (ASTM E108).

## Installation
Minimum application temperature: 40°F (4°C). Below this temperature the sealant strips may not activate and every shingle must be hand-sealed.
Minimum roof slope: 2:12. Slopes between 2:12 and 4:12 require double underlayment.
Fasteners: 1-1/4 in roofing nails (see fasteners.md).

## Warranty
Limited lifetime warranty, non-prorated for the first 10 years. Algae resistance warranty: 10 years.
