# Coil Roofing Nails 1-1/4 in (NAL-001)
Galvanised nails for pneumatic coil roofing nailers.

## Box contents
7,200 nails per box.

## How many boxes do I need?
About 22 squares per box with a 4-nail pattern (roughly 320 nails per square).
About 15 squares per box with a 6-nail pattern (roughly 480 nails per square).
A 6-nail pattern is required for high-wind ratings and on steep slopes.

## Compatibility
Suitable for all Northline asphalt shingles: Ridgeline, Summit Pro and Valor.
